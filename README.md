# Modular Studio

Download the latest signed Modular Studio installers from [Releases](https://github.com/intelligent-group/modular-studio-releases/releases/latest). Windows Setup and universal macOS DMG/ZIP downloads are available, with SHA-256 checksums.

Modular Studio runs on your computer. Version 1.8.2 introduces a redesigned Simple mode, guided creation, clearer workflow triggers and the Intelligent Group sales solution. Your existing workspace is retained when you update the app.

Install the new version to update an existing installation. An automatic updater is not included in this release.
